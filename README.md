## BGP 和 CN2 解决的不是同一件事

CN2 是中国电信自建的高速出口，优化的是电信用户出境那一段。BGP 是机房同时接入多家运营商和国际 Tier-1，按边界网关协议动态选出口。一个是对单一运营商的专线优化，一个是多线动态选路，两者不在同一个层级上。

所以“BGP 云服务器”和“CN2 云服务器”不是并列的两个档位。很多机器的接入口径是 BGP，回程里对电信那一段走 CN2。VMISS 香港 BGP 的线路拆解是个清楚的例子：电信去程 CN2、回程从电信香港 CTG 转 CN2，联通去程骨干直连、回程 AS10099 接 AS4837，移动 CMI 双程直连。三家各走各的优化路径，整体挂在 BGP 接入下面。

这也解释了另一个常见困惑：同样标着 BGP，为什么有的机器国内延迟在 40ms 量级，有的能到 150ms 以上。差别不在协议，在回程策略。野草云把自建 BGP 按回程切成三档，优质 BGP 是电信回程 CMI、联通回程 CU/NTT/CMI 均衡、移动回程 Level3；精品 BGP 三网都走骨干直连；国际 BGP 不含 CMI 和 CU，走国际方向择优选路，国内访问自然慢一截。下单时没确认档位，等于没看参数。

## 你买的是哪一类 BGP：机房多线，还是自带 IP 段

**机房多线接入**这一类，用户完全不用碰协议。野草云香港自建 BGP 接入 CMI、中国联通香港、NTT、Level3、Telstra、RETN、Cogent、HE、HKIX 等线路，再按回程策略分档出售；VMISS 的香港 BGP 分成 V1（Cloudie 机房）、V2（mega 机房）、V3（netlab 机房）三条产品线，价格和带宽档位各不相同。你买到的是“线路 + 机器”，不是“BGP 能力”。

**自带 IP 段（BYOIP）**是另一回事。Vultr 的 BGP 功能属于这一类，官方文档的原话是把自有 IP 空间带到它的任意机房使用。它的门槛在官方文档里写得很具体：

- 需要已有部署好的实例，以及自有的 IPv4 或 IPv6 地址段。有自己的 ASN 就用，没有则由平台分配一个私有 ASN。
- 广播 IPv4 前缀，实例必须有平台自动分配的 IPv4；广播 IPv6 前缀，实例要同时有 IPv4 和 IPv6。
- **最小 /24 IPv4 或 /48 IPv6**，更小的段在公网不可路由。要提交 BGP setup form 并验证 ASN 与子网所有权。
- VPS 侧参数是内部 AS 64515、IPv4 邻居 169.254.169.254、IPv6 邻居 2001:19f0:ffff::1、multihop 2；Bare Metal 侧内部 AS 是 20473、IPv4 邻居 169.254.1.1，且不向 Bare Metal 下发完整互联网 BGP 表。
- 必须**从控制面板重启实例** BGP 才生效，SSH 里重启不算。会话要求 TCP MD5 认证，所以不能用 telnet 测连通性，只能 tcpdump 抓包排查。
- 只能用实例的主 IP 建会话，不能换成别的地址。

做高可用时的规则更容易踩坑：多实例同时宣告同一个 /32，同时仍然要宣告覆盖它的 /24（IPv6 是 /48），而且**同一 /24 下的小段广播必须位于同一个 location**。官方文档写得很直接，各机房之间没有互联，一个 /24 不能拆给多个机房的不同实例用，除非你本来就在做 anycast。anycast 也不是免费的午餐，各机房 carrier mix 不同，可能出现不等价路径，官方明确说不保证连接在你选的几个机房之间均匀分布。

顺带一个冷门细节：FreeBSD 默认配置跑不了 BGP，要先 `kldload tcpmd5` 并在 `/boot/loader.conf` 里写 `tcpmd5_load="YES"`，再配 MD5 密码。

## 带宽的三种写法，实际不是一回事

| 页面上的写法 | 实际含义 | 已核验的例子 |
| --- | --- | --- |
| 200Mbps，不限流量 | 端口带宽上限，月流量不设限 | 野草云香港 VPS 2 核 1G，¥30/月 |
| 100Mbps，300GB/月 | 端口带宽 + 月流量天花板 | VMISS 香港 BGP V1 最低配，4 加元/月 |
| 50M 上行 / 200M 下行，600G | 上下行不对称，流量可加购 | 萌狐云香港精品大宽带 2H4G |

三个都写着“200M”，能做的事差得很远。端口带宽是瞬时能力，月流量是月度总量，上下行不对称则决定了你是适合建站（下行吃得多）还是适合做备份、做推流（上行吃得多）。

还有一条藏在条款里：野草云的流量型套餐超出月流量后会限速到 1Mbps，这个速度基本等于不可用；它那档 200Mbps 不限流量的套餐不存在这个问题。买之前分清自己看的是哪一档，比对比 GHz 和核数重要。

## 按场景选：哪一档够用，哪一档多数人用不上

**国内访问为主的站点和 API。** 走三网骨干直连那一档就够，不需要追国际线路。配置上 2 核 4G 起步能覆盖大部分中小站点，再往上加核之前先看瓶颈是不是在数据库或磁盘。

**外贸独立站、面向东南亚的电商。** 这时候国内延迟不是指标，国际方向的选路才是。国际 BGP 那类不含 CMI 和 CU 的产品反而更合适，价格通常也低。

**AI 应用和 API 中转。** 吃的是内存和并发连接数，不是核数。第三方测评提到野草云香港全系可以通过改主 DNS 访问主流 AI 服务，这类需求 4 核 8G 配 NVMe 基本够跑代理和转发。

**要广播自己的 IP 段。** 这一类需求跟“买哪家 VPS 便宜”无关。先确认手上有 /24 或 /48 和 ASN，再去找明确写了 BYOIP 的产品，普通 VPS 上折腾不出来。

**日活过万或者跑重数据库。** VPS 的共享宿主机在这个量级会互相抢资源，该看独立服务器了。野草云的香港独立服务器从 ¥199/月 起（E3-1230v2、16G 内存、30M 优质网或 15M 精品网），这个档位对个人项目来说多数人用不上。

续费价是第一笔。有的商家做循环折扣，续费同价；有的首年压到很低，第二年翻倍。判断方法很土，结算页切到年付看总价，再找续费说明。

## 常见问题

**境外机房的 BGP 云服务器需要备案吗？**
备案跟线路无关，跟机房所在地有关。境外（含香港）机房不涉及 ICP 备案，境内机房需要。

**买了 BGP 云服务器，就能广播我自己的 IP 段吗？**
大多数不能。机房多线接入类产品只卖线路和机器，不提供 BGP 会话。要广播自有段，得选明确支持 BYOIP 的产品，门槛是最小 /24 IPv4 或 /48 IPv6、ASN 与子网所有权验证、TCP MD5 认证。

**晚高峰会不会掉速？**
取决于回程策略和机房当前负载，不取决于“BGP”三个字。第三方测评显示 VMISS 香港 BGP 的 V1（Cloudie 机房）晚高峰带宽略低于 V2，但差距不大；V3 上线时间短、用户量小、负载低，表现反而更稳。这些数据来自不同时间、不同测试节点，只能当区间参考，不能合并成一个结论。

**标称 200Mbps 的机器实际能跑满吗？**
端口带宽是上限，实际速度还受对端、路由和共享宿主机负载影响。第三方测评提到野草云的标称带宽基本能跑满，但那是特定套餐在特定时段的结果。

**用几天不满意能退吗？**
三家口径不同：雨云 7 天无理由、每人限 3 次、日流量超 100G 取消资格；野草云 3 天内可退但收 10% 到 30% 手续费；VMISS 标的是 3 天退款保证。买之前把自己会用到的那条对上，别只看“支持退款”四个字。
